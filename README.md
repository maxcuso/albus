# Анкета Альбуса

## Что загрузить на GitHub Pages

В корне репозитория должны лежать `index.html`, `style.css`, `script.js`, `.nojekyll`
и папка `assets` со всем её содержимым. Сборка и установка зависимостей не нужны.
Исходные картинки и `Альбус.md` из папки «Гриб» для работы сайта не требуются.

## Где редактировать

- `index.html` — тексты, порядок блоков и пути к изображениям.
- `style.css` — все стили; палитры и размеры шапки находятся в начале.
- `script.js` — автоматическая и ручная смена темы.
- `assets/images` — шесть иллюстраций без изменения исходников.
- `assets/fonts` — четыре локальных шрифта.
- `assets/badge-circle.webp` — текстура кружков у заголовков.

Светлый фон: `#ffffff`. Тёмный фон: `#1a1a1a`, взят с приложенного образца.
Высота ростового арта на широком экране — `--hero-art-height: 520px`,
минимальная высота плашки — `--hero-banner-height: 280px`. Арт выступает вверх и вниз.
На телефоне фигура уходит под текст, чтобы ничего не перекрывать.

## Тема внутри iframe

По умолчанию тема автоматическая. Если форум задаёт CSS `color-scheme: light`
или `color-scheme: dark`, современный браузер может передать этот выбор внутрь iframe
через `prefers-color-scheme`, в том числе между разными доменами. Иначе используется
настройка браузера/системы. Цвета родительской страницы напрямую не читаются.

Круглая кнопка вверху переключает светлую и тёмную темы. Ручной выбор важнее
автоматического и сохраняется, если браузер разрешает localStorage внутри iframe.
Для возврата к автоматическому режиму откройте адрес с `?theme=auto`.
Адреса с `?theme=light` и `?theme=dark` задают тему при открытии.

Документация: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme

## Вставка на форум

У iframe должен быть URL опубликованного GitHub Pages, а не адрес файла на github.com.
Если используется sandbox, для кнопки и выбора темы требуется `allow-scripts`.
Высота iframe задаётся на форуме и зависит от ширины его содержимого.
